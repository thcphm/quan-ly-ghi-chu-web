# Quản lý ghi chú cá nhân (bản web)

Trang ghi chú theo môn học, chạy ngay trong trình duyệt: https://thcphm.github.io/quan-ly-ghi-chu-web/

- Ghi chú theo môn, theo bài; thêm file PDF, Word, TXT, MD làm tài liệu.
- Trợ lý T.O.M trả lời câu hỏi chỉ từ nội dung bạn đã đưa vào, có ghi nguồn. Phần AI cần khóa Gemini của riêng bạn.
- Hạn nộp bài tập, có nút thêm vào Google Calendar và tải file lịch.

Dữ liệu nằm trong trình duyệt của bạn, không gửi lên máy chủ nào. Xóa dữ liệu duyệt web là mất ghi chú, nên hãy dùng nút "Xuất dữ liệu" để giữ bản sao.

Thư mục này là bản đã dựng, không phải mã nguồn để sửa.
